# Agentic Development Process

Exploration of TBJ's agentic development workflow; how AI agents (particularly Claude Code) are used to build software, plan architecture, and accelerate development cycles.

## Core Questions

- How does working with AI agents change the development process?
- What patterns emerge in human-AI collaborative coding?
- How do you structure work to maximize agent effectiveness?
- What are the boundaries of agent autonomy in real projects?

## Context

This idea space captures conversations and insights from actual development work using Claude Code and other AI agents; particularly focused on building production systems like the Amazon SP API integration.
