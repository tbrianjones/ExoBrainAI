# Moltbot (formerly Clawdbot)  
*An Open-Source Personal AI Assistant*

**Website:** https://clawd.bot/ :contentReference[oaicite:0]{index=0}  
**GitHub:** https://github.com/moltbot/moltbot :contentReference[oaicite:1]{index=1}

## What It Is
Moltbot is an open-source, self-hosted AI assistant designed to run on your own hardware (Mac, Windows, Linux, Raspberry Pi, etc.) and interact with you through messaging platforms and local workflows. It goes beyond simple chat—Moltbot can **execute tasks, automate processes, and maintain persistent memory** on behalf of the user. :contentReference[oaicite:2]{index=2}

Moltbot has rebranded from the original *Clawdbot* name after a trademark request, but the core mission remains the same: a personal AI assistant that integrates deeply with local systems and communication channels. :contentReference[oaicite:3]{index=3}

## Core Capabilities
- **Self-hosted execution** – runs locally with user-chosen LLMs (e.g., Claude, OpenAI) without routing data through third-party servers. :contentReference[oaicite:4]{index=4}
- **Persistent context and memory** – maintains ongoing awareness across interactions. :contentReference[oaicite:5]{index=5}
- **Multi-platform integration** – connects to WhatsApp, Telegram, Discord, Slack, Signal, iMessage, Microsoft Teams, and browser/webchat interfaces. :contentReference[oaicite:6]{index=6}
- **Action automation** – capable of managing emails, calendar events, file system operations, browser tasks, and executing commands. :contentReference[oaicite:7]{index=7}
- **Extensible via “skills”** – community-built modules and plugins expand capabilities for notifications, integrations, and domain-specific automation. :contentReference[oaicite:8]{index=8}

## Why It Matters for ExoBrain
Moltbot demonstrates a **practical integration pattern** for tying large language models into real-world systems:
- Persistent AI context running 24/7 on user hardware.
- Natural language as a bridge to procedural action and task automation.
- Connectors to both external channels (chat platforms) and internal compute/workflow endpoints.
- A community ecosystem of plugins and skills that extend core functionality.

This positions Moltbot as a **reference architecture** for an ExoBrain integration layer that must:
- Orchestrate persistent agents.
- Integrate user context, memory, and action triggers.
- Support extensible plugin architectures for capabilities beyond text.
