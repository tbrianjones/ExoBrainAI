Setup Guide

Configure Claude Writer to get the most out of your ideation workflow

1. Claude Code

Required for ideation

Claude Code is the AI assistant that powers the ideation workflow. You'll use it to explore ideas, generate transcripts, and create views.

Installation Steps

  1. Download Claude Code

    Visit claude.ai/download and download the desktop app for your operating system.

  2. Open this project

    Launch Claude Code and select "Open Folder". Navigate to and select this claude_writer project folder.

  3. Start ideating

    In the Claude Code chat, type /ideate to begin exploring an idea. Claude will interview you and capture your thoughts.

Available Commands

/ideateExplore an idea through guided conversation
/generate-transcriptSave the current conversation
/generate-viewCreate content (blog, brief, essay)
/generate-poem-viewGenerate poetry

2. Google AI Studio (Gemini)

{% if status.gemini_configured %} Configured {% else %} Optional {% endif %}

Gemini enables AI-powered text and image generation. Text generation is free; image generation requires billing.

Setup Steps

  1. Get an API Key

    Go to Google AI Studio, sign in with Google, and click "Create API Key".

  2. Add the key to Replit Secrets

    In Replit, click the "Secrets" tab in the left sidebar (or press Ctrl+Shift+S). Add a new secret with key GEMINI_API_KEY and paste your API key as the value.

  3. Restart the app

    After adding the secret, restart the app for changes to take effect. Refresh this page to see the updated status.
